## 요약 (먼저 읽을 것)

세 가지가 사전 가정과 **다르게** 나왔다.

1. **병변은 희소하지 않다. p = 0.392** (학습 슬라이스의 39.2%가 병변 슬라이스).
   오버샘플링의 전제가 사실상 무너진다. q = 3p 는 **q > 1 이라 수학적으로 불가능**하다.
2. **작은 박스가 점수를 끌어내리지 않는다.** 박스 면적과 SSIM 의 상관은 0 (Spearman −0.014).
   가장 작은 박스 구간(<500px²)이 오히려 평균이 제일 높다.
3. **박스가 슬라이스보다 특별히 어렵지도 않다** — 평균적으로는. 전체 박스의 SSIM 은 자기가 속한
   슬라이스의 SSIM_full 보다 **겨우 0.0077 낮다**. 다만 이 평균은 서로 상쇄된 결과이고,
   **특정 4개 label 에서는 진짜로 무너진다** (§4). bbox loss 의 근거는 여기에만 있다.

**한 줄 결론**: 오버샘플링(w)은 정당화되지 않는다(p가 너무 크다). bbox loss(λ)는 정당화되지만
**좁게** — 4개 label 한정이고, 박스를 전부 슬라이스 수준까지 끌어올려도 총점 상한은 **+0.0099**다.
같은 시간에 **acc8 을 손보는 게 더 크다** (acc4↔acc8 격차 0.0567, bbox 전체 헤드룸의 5배 이상).

## 0. "유효 박스" 정의 (코드에서 확인, 추측 아님)

`utils/common/metrics.py::ssim_bbox` (73–83행) 의 실제 판정:

```python
win = ssim.win_size                       # SSIMLoss(win_size=7) → win = 7
x0, y0 = max(0, box["x"]), max(0, box["y"])
x1 = min(W, box["x"] + box["width"]);  y1 = min(H, box["y"] + box["height"])
if (x1 - x0) < win or (y1 - y0) < win:    # 클리핑 '후' 크기가 7 미만이면 None
    return None
```

즉 **이미지에 클리핑한 뒤의 w, h 가 둘 다 ≥ 7**. 추가로 `recon_eval.py:91` 이 `for s in range(n)`
로만 돌기 때문에 **슬라이스 인덱스 ≥ num_slices 인 annotation 키는 채점에서 무시**된다.

> **실측: 이 필터는 한 번도 발동하지 않았다.** train 2593개, leaderboard 1229개 박스 전부 통과
> (drop 0개). 데이터셋이 이미 w·h > 16 박스만 담고 있어서 win_size=7 하한이 binding 되지 않는다.
> 범위 밖 슬라이스 키도 없었다. → **유효 박스 = 전체 박스**. 하한 처리는 신경 쓸 필요 없다.

## 1. p (병변 슬라이스 비율) 과 오버샘플링 가중치 w

| | train | leaderboard (acc4+acc8) |
|---|---:|---:|
| 볼륨 | 170 (acc4 85 + acc8 85) | 80 |
| **전체 슬라이스** | **4,651** | 2,213 |
| **병변 슬라이스 (≥1 유효 박스)** | **1,824** | 920 |
| **p** | **0.392174 (39.2%)** | 0.415725 (41.6%) |
| 유효 박스 | 2,593 | 1,229 |

**슬라이스 수 정합성 확인**: 실측 4,651 = run10 의 1 epoch = 4,651 iteration 과 **정확히 일치**.
불일치 없음. acc4/acc8 중복 계수도 아니다 — 두 acc 는 별개 파일(85 + 85 = 170)이고 학습은
그 전부를 한 epoch 에 도는 게 맞다.

### w = q(1−p)/(p(1−q)) 후보표

| 목표 q | 의미 | w |
|---|---|---:|
| q = p = 0.392 | 현상 유지 | **1.000** |
| q = 2p = 0.784 | 병변 슬라이스 78% | **5.637** |
| q = 3p = 1.176 | — | **불가능 (q > 1)** |

**해석**: p 가 0.392 라서 q = 3p 는 확률이 1을 넘는다 (w 가 음수로 나옴 = 정의 붕괴).
q = 2p 조차 "학습 배치의 78%를 병변 슬라이스로" 라는 뜻이고, 그러려면 비병변 슬라이스를
사실상 버려야 한다 — SSIM_full 이 점수의 절반인데 그 대가가 너무 크다.
**오버샘플링은 이 데이터셋에서 풀 문제가 아니다.** 애초에 희소하지 않다.

### 분포 (참고)

- **볼륨당 병변 슬라이스**: train 은 170 볼륨 중 **161개가 병변을 가짐** (0개인 볼륨은 9개뿐).
  median 10, mean 10.7, max 29. leaderboard 는 80/80 전부 병변 보유 (min 4).
- **슬라이스당 박스 수** (train, 병변 슬라이스 1,824개 중): 1개 = 1,234 / 2개 = 451 / 3개 = 106 /
  4개 = 27 / 5개 = 5 / 6개 = 1. → **대부분(68%)이 박스 1개짜리.**

## 4. 결정적 통제: 박스가 "자기 슬라이스"보다 어려운가?

label 별 절대 SSIM 은 **볼륨 난이도에 오염**돼 있다 (어떤 label 이 어려운 게 아니라, 그 label 이
어려운 볼륨에 몰려 있을 수 있다). 그래서 각 박스에 대해

> **delta = (박스 SSIM) − (그 박스가 속한 슬라이스의 SSIM_full)**

를 계산했다. **delta < 0 = 박스가 자기 슬라이스보다 진짜로 어렵다** (= 모델이 병변에서 무너진다).
delta ≈ 0 이면 그 label 이 어려운 게 아니라 **볼륨이 어려운 것**이다.
CI 는 **볼륨 단위 cluster bootstrap** (같은 볼륨 내 박스는 독립이 아니므로) 2,000회.

### 읽는 법

- **모델이 실제로 무너지는 병변은 4개**, 표본도 충분하다:
  **ACL sprain (High/Low), Bone Subchondral edema, Bone-Fracture/Contusion**.
  자기 슬라이스 대비 **−0.03 ~ −0.05**, 볼륨 클러스터 부트스트랩에서도 유의. 볼륨 난이도로
  설명되지 않는 **진짜 label 효과**다. (물리적으로도 말이 된다: 저대비·미세질감 병변 —
  인대 섬유, 골수 부종. undersampling 이 가장 먼저 지우는 종류.)
- **반대로 Meniscus Tear · Joint Effusion · Cartilage 는 박스가 슬라이스보다 오히려 쉽다** (delta > 0).
  전체 평균 delta 가 −0.0077 밖에 안 되는 이유가 이것 — **어려운 label 과 쉬운 label 이 상쇄된다.**
  그래서 "박스 전체에 λ 를 균일하게 주는" 설계는 절반이 헛일이다.
- PCL Low-Mod / Bone-Lesion 도 delta 는 크게 음수지만 **볼륨 2–3개, 박스 10–12개 = 표본 부족.**
  방향은 위 4개와 같지만 이 수치로 가중치를 정하지 말 것.

## 5. 헤드룸: bbox 작업으로 실제로 벌 수 있는 점수

박스를 자기 슬라이스 수준까지 끌어올린다고 가정한 **상한** (총점 = 0.5·full + 0.5·bbox 이므로 총점 기여 = ½):

| 시나리오 | SSIM_bbox | Δbbox | **Δ총점** |
|---|---:|---:|---:|
| run10 현재 | 0.9021 | — | — |
| **모든** 박스가 자기 슬라이스 수준 도달 | 0.9218 | +0.0197 | **+0.0099** |
| **4개 hard label 만** 슬라이스 수준 도달 (전체 박스의 35.5%) | 0.9175 | +0.0154 | **+0.0077** |

**비교: acc4 ↔ acc8 격차는 SSIM_bbox 0.0567, SSIM_full 0.0481.**

즉 bbox 를 **완벽하게** 고쳐도 총점 +0.0099 가 천장인데, acc8 쪽 격차는 그 5배가 넘는다.
bbox loss 는 "공짜에 가까우면 넣을 만한" 수준이지, 지금 최우선 레버가 아니다.

## 6. 결론 — 오버샘플링·bbox loss 는 정당화되는가?

**병변이 실제로 희소한가? → 아니다.** p = 0.392. 학습 슬라이스의 40%가 병변 슬라이스이고,
170 볼륨 중 161개가 병변을 갖는다. **오버샘플링(w)은 정당화되지 않는다** — q = 3p 는 애초에
불가능하고(q > 1), q = 2p 도 배치의 78%를 병변으로 채운다는 뜻이라 SSIM_full(점수의 절반)을
희생한다. **w 는 배선하지 말 것을 권고.**

**모델이 특정 label 에서 실제로 무너지는가? → 그렇다. 단 4개 label 에서만.**
ACL sprain(High/Low) · Subchondral edema · Bone-Fracture 는 자기 슬라이스 대비 −0.03~−0.05,
볼륨 클러스터 부트스트랩에서도 유의. **bbox loss(λ)는 정당화되지만 좁게** — 그리고
**균일 λ 는 부적절**하다. Meniscus Tear·Joint Effusion·Cartilage 박스는 이미 슬라이스보다
쉬워서(delta > 0), 균일 λ 는 이미 잘 되는 곳에도 똑같이 힘을 준다.

**하지만 우선순위는 bbox 가 아니다.** bbox 완전 해결의 총점 상한이 **+0.0099** 인 반면,
acc8 격차는 **0.0567**(bbox) / **0.0481**(full) 이다. 그리고 위 4개 hard label 의 열세도
**acc8 에서 훨씬 심하다** (예: Bone-Fracture acc4 0.9041 → acc8 0.8118). 즉 "병변 문제"의
상당 부분이 실은 **acc8 문제**다. **acc8 복원 품질을 올리면 full·bbox 가 동시에 오른다.**

### 권고 (다음 단계)

1. **오버샘플링(w) 드롭.** p = 0.392 에서는 풀 문제가 아니다.
2. **λ 를 넣는다면** 균일 λ 가 아니라 **4개 hard label 한정**, 그리고 **작은 λ**로. 기대 이득이
   +0.008 수준이므로 SSIM_full 을 조금이라도 깎으면 순손실이다. 배선 후 full 이 떨어지지 않는지
   반드시 확인.
