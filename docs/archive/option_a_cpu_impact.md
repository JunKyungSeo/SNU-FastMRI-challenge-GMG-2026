# 옵션 A(로컬 CPU 검증)가 내 컴퓨터에 미치는 영향 분석

> 옵션 A = venv에 **CPU 전용 torch + MONAI**를 깔고 `pytest tests/`를 돌려 **SDUM 어댑터가 실제로 도는지 검증**하는 것. (GPU 불필요, 하지만 설치는 필요.)

## 지금 이 컴퓨터 상태 (측정값)
- **디스크(C:) 여유: 5.4 GB** (98% 참) ← ⚠️ **가장 큰 문제**
- **RAM 여유: 0.4 GB / 총 7.7 GB** (지금 앱이 많이 떠 있음)
- venv 아직 없음(설치 이력 없음).

## A가 실제로 하는 일 & 영향

| 항목 | 내용 | 영향/리스크 |
|---|---|---|
| **디스크 설치** | `.venv`에 CPU torch(~2GB) + MONAI·deps(~0.5~1GB) 등 → **총 ~2.5~3.5GB** | ⚠️ **여유 5.4GB에서 설치하면 ~2GB만 남음.** Windows는 디스크가 거의 꽉 차면 **느려지고 불안정**(페이징/임시파일 공간 부족). **이대로는 위험.** |
| **RAM 사용** | tiny 테스트 모델(cascade 2, 채널 16/32) CPU forward+backward → **1~3GB** 필요 추정 | ⚠️ 지금 여유 0.4GB. **앱 많이 닫아야** 함. 부족하면 스왑으로 매우 느려지거나 테스트 실패. |
| **설치 시간** | CPU torch/MONAI 다운로드 | 네트워크 따라 **수 분**. |
| **테스트 실행 시간** | Restormer 어텐션을 CPU로 → 느림 | 테스트당 **수십 초~수 분**. CPU 100%·발열(일시적). |
| **관리자 권한** | 불필요 | venv는 사용자 폴더에만 씀. |

## 되돌리기(원복) — 이건 안심해도 됨
- **완전히 되돌릴 수 있음.** `.venv/` 폴더 하나만 지우면 설치한 것 **전부 사라짐**.
- **전역 파이썬(3.13)·시스템·레지스트리 안 건드림.** `.gitignore`에 `.venv/` 넣어 git에도 안 올라감.
- 즉 **컴퓨터에 영구적 손상·흔적 없음.** 유일한 실질 리스크는 위의 **"디스크가 꽉 차서 생기는 일시적 시스템 불안정"** 뿐 → 그래서 **디스크 확보가 전제**.

## 결론 & 선택지
지금 **디스크 5.4GB·RAM 0.4GB**로는 로컬 A를 **바로 하기엔 빡빡/위험**하다. 세 갈래:

1. **디스크 확보 후 로컬 A** — C:에서 최소 **10GB+ 여유** 만들고(불필요 파일/캐시 정리), 무거운 앱 닫고 진행. → 그럼 A 안전하게 가능.
2. **Colab로 A 대체 (권장, 로컬 부담 0)** — Google Colab 무료(디스크·RAM·심지어 GPU 다 클라우드). repo만 올리거나 clone해서 `pytest` 실행. **내 컴퓨터 디스크/RAM 전혀 안 씀.** 검증 목적엔 이게 제일 깔끔.
3. **A 보류, 무설치 작업 계속** — 지금은 C3(bbox 스캐폴딩)·C4(코드 리뷰)만 하고, 검증은 GPU 서버 확보 때 한 번에.
